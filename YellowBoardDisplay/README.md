# Emerald OS — ESP32-2432S028 (Yellow Board Display)

**Emerald** — це персональний гаджет юного програміста, створений спеціально для 9-річного Федора.
Прошивка для плати розробника **ESP32-2432S028** (Elecrow 2.8" TFT Touch Display) з фірмовим зеленим неоновим стилем.

### ✨ Можливості
- **Boot анімація** — логотип Emerald з ефектом світіння та термінальними рядками запуску; тапніть для пропуску
- **Story Mode** — анімовані картки досягнень при першому запуску
- **Головне меню** — навігація по всіх екранах (тач- інтерфейс)
- **Профіль** — інформація про користувача (Fedir, Junior Developer, Level 9)
- **Архів** — збережені нотатки та дані
- **Spy Tools** — WiFi сканер, вибір мережі, введення пароля та підключення
- **Ігри** — вбудована гра Snake (Змійка)
- **Консоль** — псевдо-термінал з командами: `help`, `whoami`, `status`, `about` та інші
- **About** — лист від батьків з ефектом друкарської машинки
- **RGB LED** — індикація стану системи (heartbeat, tap-flash, alarm)

### 🧩 Характеристики плати

| Параметр | Значення |
|----------|----------|
| **SoC** | ESP32 (240 MHz, 2 ядра) |
| **RAM** | 320 KB SRAM + 4 MB PSRAM (опціонально) |
| **Flash** | 4 MB |
| **Дисплей** | ST7789 (або ILI9341, залежить від ревізії), 2.8", 320×240, SPI |
| **Тачскрін** | XPT2046, SPI |
| **Wi-Fi** | 802.11 b/g/n |
| **Bluetooth** | BLE 4.2 + Classic |

> ⚠️ **ВАЖЛИВО:** Плати ESP32-2432S028 мають різні ревізії, які відрізняються:
> - **Драйвер дисплея:** ILI9341 (старі ревізії, VSPI) або **ST7789** (нові ревізії, HSPI)
> - **SPI порт:** VSPI (SPI3, піни 23/19/18) або **HSPI** (SPI2, піни 13/12/14)
> - Конфігурація в `src/tft_setup.h` повинна відповідати вашій ревізії плати

### ⚠️ Діагностика дисплея: білий екран на новій платі (28.05.2026)

При заміні плати на нову (та ж модель ESP32-2432S028) дисплей показував **білий екран**, тач не працював, світлодіод горів без реагування на дотик.

#### Симптоми

| Симптом | Деталі |
|---------|--------|
| **Екран** | Білий, текст/кольори не видно |
| **LED** | Горить синій та зелений, не реагує на тач |
| **Тач** | Не працює |
| **Serial** | `[OK] Display init SUCCESS`, але всі регістри = `0xFF` |

#### Процес діагностики

| Крок | Зміна | Результат |
|------|-------|-----------|
| 1 | `ILI9341_DRIVER` + VSPI (23/19/18) + CS=15 | ❌ Білий екран, регістри `0xFF` |
| 2 | `ILI9341_2_DRIVER` + VSPI + CS=15 | ❌ Білий екран |
| 3 | `ST7789_DRIVER` + VSPI + CS=15 | ❌ Білий екран |
| 4 | `ST7789` + VSPI + CS=-1 | ❌ Білий екран |
| 5 | `ST7789` + **HSPI** (13/12/14) + CS=-1 | ⚠️ Регістри змінилися з `0xFF` на `0x00` |
| 6 | `ILI9341_DRIVER` + **HSPI** + CS=15 | ⚠️ **Реальні ID!** `RDID1=0x10, RDID2=0x81, RDID3=0xB3` |
| 7 | `ST7789_DRIVER` + **HSPI** + CS=15 | ✅ **Дисплей працює!** |

#### Ключове відкриття

**Читання ID-регістрів через SPI** (команди `0xDA`, `0xDB`, `0xDC`) показало:

```
# Очікувані значення для ILI9341:
RDID1(0xDA)=0x00  RDID2(0xDB)=0x93  RDID3(0xDC)=0x41

# Фактичні значення на новій платі:
RDID1(0xDA)=0x10  RDID2(0xDB)=0x81  RDID3(0xDC)=0xB3
```

- **Не ILI9341** (0x93 → 0x81, 0x41 → 0xB3)
- Display physically connected to **HSPI** (SPI2: MOSI=13, MISO=12, SCLK=14), **not VSPI** (SPI3: 23, 19, 18)
- Потребує `ST7789_DRIVER` замість `ILI9341_DRIVER`
- **CS повинен керуватися бібліотекою** (`TFT_CS=15`, не `-1`)

#### Першопричина

Нова ревізія плати ESP32-2432S028 використовує:
1. **HSPI** (SPI2) замість VSPI (SPI3) для дисплея
2. **ST7789** контролер замість ILI9341
3. Стандартний CYD-пінout (CS=15, DC=2, RST=4, BL=32), але на іншому SPI-порту

#### Фінальна робоча конфігурація

Встановлюється в [`src/tft_setup.h`](src/tft_setup.h):

```cpp
#define ST7789_DRIVER
#define TFT_MISO   12    // HSPI (SPI2)
#define TFT_MOSI   13
#define TFT_SCLK   14
#define TFT_CS     15    // CS під керуванням бібліотеки!
#define TFT_DC      2
#define TFT_RST     4
#define TFT_BL     32
#define USE_HSPI_PORT     // HSPI замість VSPI
```

## 💡 RGB LED — калібрування пінів (29.05.2026)

Плата має вбудований RGB світлодіод (common anode, LOW=ON). Заводське підключення на цій ревізії:

| Колір | GPIO | Примітка |
|-------|------|----------|
| 🔴 Червоний | **GPIO26** | Тьмяний — спільний зі спикером (buzzer) |
| 🟢 Зелений | **GPIO16** | Яскравий |
| 🔵 Синій | **GPIO17** | Яскравий |

**Поведінка LED у Emerald:**
- **За замовчуванням** — не світиться
- **Зелений** — повільно блимає (heartbeat) під час роботи
- **Синій** — ледь помітно блимає при кожному тапі по екрану
- **Червоний** — блимає 15 секунд після 10 тапів

> ⚠️ GPIO26 також підключений до спикера — через це червоний діод тьмяний. Це апаратна особливість, не проблема коду.

## 🛠 Як зібрати та завантажити

### 1. Встановити PlatformIO

```bash
pip install platformio
```

або через **VS Code**: встановити розширення [PlatformIO IDE](vscode:extension/platformio.platformio-ide).

### 2. Зібрати проєкт

```bash
pio run
```

### 3. Завантажити на плату

Підключіть ESP32 через USB, знайдіть порт:

```bash
pio device list
```

Вкажіть порт у `platformio.ini` (розкоментуйте `upload_port`) або завантажте одразу:

```bash
pio run --target upload
```

### 4. Моніторинг Serial

```bash
pio device monitor
```
