# 🏚️ House Flopper — Реставрація будинків

**House Flopper** — гра про реставрацію старих занедбаних будинків.

## 🎮 Геймплей

- Отримуйте замовлення від клієнтів через телефон
- Заходьте в будинки та оцінюйте стан кімнат
- Викидайте сміття 🗑️
- Фарбуйте стіни 🎨
- Ремонтуйте: цвяхи, ручки, дірки, дошки, протічки, дроти, плитку, вікна, дах, фасад
- Купуйте інструменти в майстерні
- Розвивайте свій бізнес

## 🕹️ Керування

| Клавіша | Дія |
|---------|-----|
| `1` | Відро для сміття |
| `2` | Валик для фарбування |
| Клік | Взаємодія з об'єктами |

## 🛠 Технології

- Чистий HTML/CSS/JS
- Система кімнат та інвентарю
- Економічна система

## 🚀 Запуск

Відкрийте `index.html` у браузері.
