# 🧱 Грушик — Ремонт квартири

**Grushyk: Apartment Renovation** — гра-симулятор ремонту, де ви будуєте стіни з газоблоків.

## 🎮 Геймплей

- Купуйте матеріали: газоблоки, цемент, клей-піну
- Клікайте по сітці, щоб будувати стіну
- Газоблоки ставляться один на одного
- Заливайте газоблоки піною або цементом для міцності
- Слідкуйте за прогресом ремонту

## 🕹️ Керування

🖱️ Клікай по сітці, щоб будувати стіну

## 🛠 Технології

- Чистий HTML/CSS/JS
- Canvas 2D
- Система ресурсів та економіки

## 🚀 Запуск

Відкрийте `index.html` у браузері.
