# 🏡 Чіча — Домик на дереві

**Chicha: Treehouse Builder** — гра про будівництво та облаштування будиночка на дереві.

## 🎮 Геймплей

- Збирайте ресурси: дерево 🪵, каміння 🪨, скло 🪟
- Рубіть дерева сокирою 🪓
- Добувайте каміння киркою ⛏️
- Будуйте: підлогу, стіни, дах, вікна, двері, балкон, огорожу, драбину
- Додавайте поверхи до будиночка
- Купуйте меблі для інтер'єру
- Продавайте ресурси за крони

## 🕹️ Керування

| Клавіша | Дія |
|---------|-----|
| `WASD` | Ходити |
| `← →` | Повернути голову |
| `ПКМ / E` | Рубнути |
| `Q / 1 / 2` | Змінити інструмент |

## 🛠 Технології

- Чистий HTML/CSS/JS
- 2D-гра з видом збоку
- Система крафту та будівництва

## 🚀 Запуск

Відкрийте `index.html` у браузері.
