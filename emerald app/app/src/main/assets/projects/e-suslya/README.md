# Е-сусля: Погляд у темряву (3D)

**E-suslya: Gaze into the Darkness**

Імерсивна 3D-гра жахів на основі браузера, написана на чистому JavaScript з використанням Three.js та PeerJS.

## 🕯️ Сюжет

Двоє культистів переплутали свічку та дзеркало в ритуалі. Замість покірного духа з'явилося **ЩОСЬ** зле. Гравці повинні виживати в темній кімнаті, виявляючи аномалії та уникаючи небезпек.

## 🎮 Геймплей

- **Самотня гра** — проходьте рівні, знаходячи аномалії в кімнаті
- **Кооператив** — грайте з другом через P2P-з'єднання (PeerJS)
- **Рівні:** 5 основних рівнів + безкінечний режим
- **Аномалії:** предмети, що зникли, змістилися або з'явилися; небезпечні зони

## 🕹️ Керування

| Клавіша | Дія |
|---------|-----|
| `WASD` | Рух по кімнаті |
| `F` | Увімкнути/вимкнути ліхтарик |
| `1` | Вибрати "Немає аномалії" |
| `2` | Вибрати "Аномалія" |
| `Пробіл / Клік` | Взаємодія / ходьба до точки |
| `Shift` | Прискорення |

## 🛠 Технології

- **Three.js** — 3D-рендеринг (версія r128)
- **PeerJS** — P2P-мультиплеєр (WebRTC)
- Чистий HTML/CSS/JS — без білд-систем та залежностей

## 🚀 Запуск

Просто відкрийте `index.html` у будь-якому сучасному браузері:

```bash
open index.html
```

Або використовуйте локальний сервер (рекомендовано для мультиплеєра):

```bash
npx serve .
```
