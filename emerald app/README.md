# Emerald App 🌿

**Emerald App** — це мобільний додаток на Android (Kotlin + Jetpack Compose), який об'єднує всі ваші проєкти в одному місці. Встановлюйте додатки з каталогу, відкривайте їх через WebView на робочому столі та користуйтесь вбудованим AI-ботом.

## Можливості

### 📱 Робочий стіл
- Встановлені додатки відображаються як іконки з назвами (як на справжньому робочому столі)
- Кожен додаток має унікальну іконку та колір
- При натисканні відкривається WebView з HTML-сторінкою додатку
- Підтримка JavaScript, масштабування, навігації всередині WebView
- Зовнішні посилання автоматично відкриваються в браузері

### 🛍️ Додатки (каталог)
- Перегляд доступних проєктів
- Встановлення додатків на робочий стіл одним натисканням
- Статус встановлення для кожного додатку

### 🤖 BotShe (AI-бот)
- Вбудований чат-бот з підтримкою AI
- Можливість використання локальної AI-моделі

### 👤 Акаунт
- Реєстрація та вхід через **Emerald Account**
- Перегляд інформації про акаунт
- Вихід з акаунту

## Вимоги

- **Android Studio** (остання версія) — завантажити з https://developer.android.com/studio
- **Java 17+** (встановлюється разом з Android Studio)
- **Android SDK 34+**

## Як запустити

1. Встанови **Android Studio**
2. Відкрий папку `Emerald App` в Android Studio
3. Дочекайся синхронізації Gradle (Android Studio завантажить все необхідне)
4. Натисни **Run** (зелений трикутник) або `Ctrl + R`
5. Обери емулятор або підключи реальний Android пристрій

## Як це працює

- **Реєстрація** — створи новий акаунт (email + пароль)
- **Вхід** — увійди в існуючий акаунт
- **Робочий стіл** — перегляд та відкриття встановлених додатків
- **Додатки** — каталог доступних проєктів для встановлення
- **BotShe** — спілкування з AI-ботом
- **Акаунт** — керування профілем та вихід

> Наразі дані зберігаються в пам'яті додатку. В майбутньому можна підключити Firebase для хмарного зберігання.

## Технології

- **Kotlin** — мова програмування
- **Jetpack Compose** — інтерфейс користувача
- **Navigation Compose** — навігація між екранами
- **Material 3** — дизайн (зелена emerald тема)
- **Coroutines** — асинхронні операції
- **WebView** — відображення HTML-додатків
- **OkHttp** — HTTP-запити для AI
- **Gson** — JSON парсинг
