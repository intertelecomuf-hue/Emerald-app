# Emerald — Віртуальний помічник

![Version](https://img.shields.io/badge/version-1.0.0-green)

**Emerald** — це інтелектуальний віртуальний помічник, доступний як веб-застосунок та настільний додаток (Windows Desktop). 
Проєкт поєднує серверну логіку на Node.js/Express з десктопною оболонкою Electron, надаючи зручний інтерфейс для спілкування, обчислень, перекладу, визначень термінів та роботи з електронною поштою.

---

## Можливості

- **Чат-бот** — природномовне спілкування українською мовою
- **Математичні обчислення** — розв'язання виразів (+, -, *, /, ^, дужки)
- **Переклад фраз** — простий переклад українських фраз англійською (і навпаки)
- **Визначення термінів** — пояснення понять зі сфери IT (ШІ, машинне навчання, алгоритми тощо)
- **Підсумовування тексту** — скорочення довгих текстів до кількох речень
- **Час та дата** — поточний час і дата
- **Електронна пошта** — створення та перегляд листів через API (зберігання у JSON)
- **Налаштування інтерфейсу** — зміна кольорової схеми, аватарки, мови, теми фону
- **Desktop-додаток** — повноцінний Windows-застосунок на Electron

```

├── public/                  # Клієнтські файли інтерфейсу
│   ├── index.html           # Головна сторінка
│   ├── styles.css           # Стилі
│   ├── script.js            # Клієнтська логіка
│   └── favicon.ico          # Іконка

├── build.bat                # Скрипт збірки (Windows)
├── install-node.ps1         # Скрипт встановлення Node.js
└── run-server.ps1           # Скрипт запуску сервера
```

## Запуск

### 1. Звичайний запуск (веб-сервер)

```bash
npm install
npm start
```

Сервер буде доступний за адресою [http://localhost:3000](http://localhost:3000).

### 2. Швидкий запуск (Windows PowerShell)

```powershell
.\install-node.ps1       # Встановити Node.js (адміністратор)
.\run-server.ps1         # Запустити сервер
```

### 3. Docker

```bash
docker build -t emerald-backend .
docker run -p 3000:3000 --rm --name emerald-backend emerald-backend
```

### 4. PM2 (продакшен)

```bash
npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
```

### 5. Electron (десктоп)

```bash
npm run electron-start    # Запуск у режимі розробки
npm run dist              # Збірка Portable-версії
```
